# Site da Luise Designer

Site/portfólio da Luise Designer (Goiânia-GO). HTML + CSS puros, sem build.

- `index.html`: página inicial (menu, hero, serviços, projetos, números, depoimentos, sobre, contato)
- `css/style.css`: todos os estilos (cores e fontes no topo, em `:root`)
- `fonts/`: Antonio e Quicksand (licença OFL), hospedadas no próprio site
- `img/`: logo, fotos, ícones e `img/projetos/` com as capas dos projetos

Publicado com GitHub Pages a partir da branch `main`.
